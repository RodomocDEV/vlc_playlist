# VLC Playlist Generator

Petit utilitaire Windows permettant de créer automatiquement une playlist VLC à partir d'un dossier contenant des séries ou vidéos.

## Fonctionnalités

* Sélection d'un dossier principal.
* Recherche automatique des fichiers vidéo `.mkv` dans tous les sous-dossiers.
* Tri automatique par ordre alphabétique (saison, épisode).
* Génération d'une playlist `.m3u`.
* Lancement automatique de VLC avec la playlist créée.
* Interface simple basée sur Windows Forms.
* Gestion des erreurs (VLC absent, aucun fichier trouvé).

## Utilisation

1. Lancez l'application.
2. Sélectionnez le dossier contenant votre série.
3. L'application crée la playlist automatiquement.
4. VLC démarre avec tous les épisodes dans le bon ordre.

## Compatibilité

* Windows 10 / Windows 11
* VLC Media Player
* Fichiers vidéo `.mkv`

Aucun fichier vidéo n'est modifié, seule une playlist temporaire est créée.
